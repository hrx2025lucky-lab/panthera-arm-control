             二连杆机械臂 RBF 神经网络自适应控制
                      基于万能逼近理论的智能控制系统设计与实现


本文档系统介绍了基于径向基函数 (RBF) 神经网络的二连杆机械臂自适应控制系统。利用 RBF
网络的万能逼近能力, 系统能够在线学习和补偿未知的非线性动力学, 无需精确的系统模型。文
档详细阐述了 RBF 网络原理、自适应控制律设计、李雅普诺夫稳定性证明, 并通过 MATLAB
仿真平台验证了控制系统的优异性能。相比传统 PID 和模型自适应控制,RBF 方法展现出更强
的适应性和鲁棒性。


1 RBF 神经网络理论基础

1.1 万能逼近定理

RBF 神经网络是一种前馈神经网络, 具有强大的非线性函数逼近能力。根据万能逼近定理 (Uni-
versal Approximation Theorem):

    对于任意连续函数 f : Rn → Rm , 以及任意精度 ϵ > 0, 存在一个 RBF 网络使得:

                            ∥f (x) − W∗T H(x)∥ < ϵ,        ∀x ∈ Ω

    其中 Ω 是紧集,W∗ 是理想权重矩阵,H(x) 是基函数向量。

这一性质使得 RBF 网络特别适合逼近复杂的机械臂逆动力学函数。

1.2 RBF 网络结构

RBF 网络采用三层结构:

1. 输入层: 接收输入向量 x ∈ Rnin
2. 隐层: N 个径向基神经元, 每个神经元对应一个中心 cj 和宽度 bj
3. 输出层: 线性加权求和, 输出 y = WT H(x)

高斯基函数:
最常用的径向基函数是高斯函数:
                                   (              )
                                     ∥x − cj ∥2
                      Hj (x) = exp −                  ,   j = 1, 2, . . . , N   (1)
                                        2b2j

基函数向量:
                        H(x) = [H1 (x), H2 (x), . . . , HN (x)]T ∈ RN           (2)

网络输出:
                                       y(x) = WT H(x)                           (3)

其中 W ∈ RN ×m 是权重矩阵,m 是输出维度。

1.3 RBF 网络特点

• 局部逼近性: 每个基函数只对输入空间的局部区域响应, 具有良好的泛化能力
• 学习速度快: 隐层参数 (中心和宽度) 可以预先固定, 只需学习线性权重
• 避免局部极小: 输出层权重学习是凸优化问题
• 结构简单: 相比多层感知器, 结构更简单, 易于分析

2 RBF 自适应控制理论

2.1 系统动力学与控制目标

二连杆机械臂的动力学方程:

                       M(q)q̈ + C(q, q̇)q̇ + G(q) + F(q̇) = τ           (4)

控制目标: 给定期望轨迹 qd (t), 设计控制律 τ 使得 limt→∞ ∥e(t)∥ = 0, 其中 e = qd − q。
挑战: 动力学矩阵 M, C, G, F 可能未知或难以精确建模。

2.2 逆动力学逼近

理想的逆动力学控制律为:

                     τ ∗ = M(q)q̈r + C(q, q̇)q̇r + G(q) + F(q̇r )       (5)

其中 q̇r = q̇d + Λe 是参考速度,q̈r = q̈d + Λė 是参考加速度。
定义滤波跟踪误差:
                                 r = ė + Λe = q̇ − q̇r                 (6)

核心思想: 使用 RBF 网络逼近未知的逆动力学函数 f (x):

                    f (x) = M(q)q̈r + C(q, q̇)q̇r + G(q) + F(q̇r )      (7)

构造输入向量:
                          x = [qT , q̇T , qTd , q̇Td , q̈Td ]T ∈ R10    (8)

根据万能逼近定理:
                              f (x) = W∗T H(x) + ϵ(x)                   (9)

其中 W∗ ∈ RN ×2 是理想权重,ϵ 是逼近误差 (有界)。

2.3 RBF 自适应控制律

由于理想权重 W∗ 未知, 使用估计值 Ŵ(t) 设计控制律:


                                  τ = ŴT H(x) + Kr                    (10)

其中:

                                              2
• ŴT H(x): RBF 网络输出, 逼近逆动力学
• Kr: 反馈控制项, 提供阻尼和鲁棒性
• K = diag(k1 , k2 ) > 0: 反馈增益矩阵

权重更新律:
采用梯度下降法设计自适应律:
                                            ˙
                                           Ŵ = ΓH(x)rT                      (11)

其中 Γ > 0 是学习率 (标量或矩阵)。

     3.4 关键技术要点

     1. RBF 中心选择
     中心在输入空间均匀分布:
1                  rng (1);   % 固定随机种子保证可复现
2                  center_range = 2.0;
3                  centers = center_range * 2 * (rand(input_dim , N) - 0.5);


     中心范围 [−2, 2] 覆盖了典型的角度、速度和加速度范围。
     2. 宽度参数调节
     宽度影响基函数的覆盖范围:

     • 宽度太小: 局部性强, 但可能产生” 盲区”
     • 宽度太大: 泛化能力强, 但逼近精度下降
     • 本例选择 b = 1.8, 平衡了局部性和泛化性

     3. 学习率选择
     Γ = 600 是通过试验调节得到的:

     • 太小: 学习速度慢, 初始误差大
     • 太大: 可能导致数值不稳定或振荡

     4. 摩擦力平滑处理
     使用 tanh 函数代替 sign 函数:
1                  F = Fc * [tanh (100* dq (1)); tanh (100* dq (2))];


     这显著提高了 ODE 求解器的数值稳定性。

7.2 控制性能评价

优点:

• 无需精确模型, 适应性极强
• 能够学习任意复杂的非线性动力学
• 稳态跟踪精度高 (< 0.002 rad)
• 收敛速度快 (约 2 秒)
• 对参数不确定性和外部扰动鲁棒

局限性:

• 计算复杂度高, 实时性受限
• 需要大量参数调节 (中心、宽度、学习率等)
• 初始学习阶段性能较差
• 高维状态空间 (304 维) 对内存要求高
• 缺乏理论指导的参数选择方法

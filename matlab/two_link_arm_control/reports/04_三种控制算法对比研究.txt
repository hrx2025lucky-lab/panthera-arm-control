                二连杆机械臂控制算法对比研究
               PID、模型自适应与 RBF 神经网络控制的理论与实践


本文档详细介绍了二连杆机械臂控制中三种主流方法的理论基础：比例-积分-微分（PID）控制、
基于模型的自适应控制（MBAC）以及基于径向基函数神经网络（RBF-NN）的自适应控制。文
档深入阐述了每种方法的数学模型、控制律推导和稳定性分析，并通过一个统一的 MATLAB 仿
真试验平台对它们的性能进行了量化对比和分析。


1 系统动力学模型与控制目标

1.1 二连杆机械臂动力学

机械臂系统通常被建模为欧拉-拉格朗日（Euler-Lagrange）系统。对于一个 n 自由度的机械臂，
其动力学方程可以表示为：


                     M(q)q̈ + Vm (q, q̇)q̇ + G(q) + Fd (q̇) = τ            (1)

其中：

• q, q̇, q̈ ∈ Rn ：关节角度、速度和加速度向量。
• M(q) ∈ Rn×n ：惯量矩阵（正定、对称）
                         。
• Vm (q, q̇) ∈ Rn×n ：科里奥利力和离心力矩阵。
• G(q) ∈ Rn ：重力项向量。
• Fd (q̇) ∈ Rn ：摩擦力项向量。
• τ ∈ Rn ：控制力矩输入向量。

关键动力学特性：

1. 有界性：惯量矩阵满足 λmin (M)I ≤ M(q) ≤ λmax (M)I。
2. 斜对称性：矩阵 Ṁ(q) − 2Vm (q, q̇) 是斜对称的。该性质对基于能量（Lyapunov）的稳定性分
  析至关重要。
3. 参数线性化（LIP）
            ：动力学方程可以表示为关于一组常数物理参数 Θ 的线性形式：

                  M(q)q̈ + Vm (q, q̇)q̇ + G(q) + Fd (q̇) = Y(q, q̇, q̈)Θ   (2)

  其中 Y 是回归矩阵（Regressor Matrix）
                             。

1.2 控制目标

给定一个期望的关节轨迹 qd (t)，及其导数 q̇d (t) 和 q̈d (t)。控制目标是设计控制力矩 τ ，使得实
际关节角度 q(t) 能够精确跟踪期望轨迹。定义跟踪误差为：

                                 e(t) = qd (t) − q(t)                      (3)

目标是使 limt→∞ ∥e(t)∥ = 0。

2.1 方法一：比例-积分-微分（PID）控制

PID 控制是一种不依赖于系统精确模型的经典反馈控制方法。
控制律设计

闭环系统分析

                                                               ∫
               M(q)ë + (Vm (q, q̇) + KD )ė + KP e + KI           edτ = η(t)   (5)

其中 η(t) 包含了系统动态的复杂非线性项和耦合项。
特点：PID 实现简单，通过反馈抑制不确定性。但理论上难以保证全局渐近稳定，且在高动态任
务中性能受限于其固定增益结构。

2.2 方法二：基于模型的自适应控制（MBAC）

MBAC 利用了系统动力学的结构已知性（LIP 特性），但假设物理参数 Θ 未知。通过在线估计
参数 Θ̂(t) 来实现精确控制。本研究采用经典的 Slotine-Li 自适应控制算法。
控制律设计
定义滤波误差（滑模面）r(t)：
                                 r(t) = ė(t) + Λe(t)                           (6)

其中 Λ 是正定对角矩阵，决定了误差收敛速度。
定义参考速度 q̇r 和参考加速度 q̈r ：

                           q̇r = q̇d + Λe,       q̈r = q̈d + Λė                (7)

利用 LIP 特性，我们可以构造一个回归矩阵 Yr (q, q̇, q̇r , q̈r )，使得：

2.3 方法三：RBF 神经网络自适应控制（RBF-NN）

RBF-NN 控制利用神经网络的万能逼近能力来学习和补偿系统未知的非线性动态，不要求知道
动力学结构。
RBF 网络模型与逼近
RBF 网络用于逼近未知的非线性函数。我们将整个逆动力学（Eq. 8）视为一个待逼近的函数
f (x)：
                         f (x) = M(q)q̈r + Vm (q, q̇)q̇r + G(q) + Fd (q̇)   (14)

输入向量通常选择为 x = [qT , q̇T , qTd , q̇Td , q̈Td ]T 。

• PID 和 MBAC 的计算效率极高。
• RBF-NN 的计算成本显著高于前两者（约 20 倍）。这是由于其高维的状态向量（304 维）

5 结论

本研究对比了 PID、MBAC 和 RBF-NN 在二连杆机械臂轨迹跟踪任务中的性能。

1. 精度与性能：RBF-NN 展现出最高的跟踪精度和最快的收敛速度，证明了神经网络在处理复
 杂非线性系统中的优势。MBAC 利用结构信息，性能优于 PID。
2. 模型依赖性：PID 不依赖模型。MBAC 依赖于动力学结构已知。RBF-NN 理论上不依赖模型
 结构，适应性最强。
3. 权衡：RBF-NN 的高性能是以显著增加的计算成本为代价的。在实际应用中，需根据精度要
 求、计算资源和对系统模型的了解程度，权衡选择合适的控制策略。

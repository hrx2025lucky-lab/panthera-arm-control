1       机器人动力学基础




1.1 引言：从牛顿到拉格朗日
    机器人动力学研究力与运动的关系。虽然牛顿力学可以描述机械臂的运动，但对于多
关节系统，约束力的处理极其复杂。拉格朗日方法基于能量原理，自动消除约束力，使得复
杂机械系统的建模变得系统化和程序化。

       拉格朗日函数

    拉格朗日函数定义为系统动能与势能之差：

                    L(q, q̇) = T (q, q̇) − V (q)

    其中 T 为动能（与速度相关），V 为势能（与位置相关）。通过拉格朗日方程：
                       
                     d ∂L      ∂L
                             −     = τi
                    dt ∂ q̇i   ∂qi

    可直接得到系统的运动方程。

 E-L 动力学方程

                       M (q)q̈ + Vm (q, q̇)q̇ + F (q̇) + G(q) = τ   (1)


  让我们详细解析方程中每一项的物理含义：

       符号             名称              物理意义

       M (q)q̈        惯性力矩            使关节产生角加速度所需的力矩，类似
                                      F = ma
       Vm (q, q̇)q̇   向心/科氏力矩 由于关节速度引起的非线性耦合效应
       F (q̇)         摩擦力矩            关节轴承、齿轮等产生的阻尼作用
       G(q)           重力矩             连杆自重产生的力矩，与姿态相关
       τ              控制力矩            电机施加的驱动力矩（我们的控制输
                                      入）


1.3 三个关键性质

 定理 1.1: 惯性矩阵的正定性
 惯性矩阵 M (q) 对所有构型 q 均满足：

                                µ1 In ⪯ M (q) ⪯ µ2 In

 其中 µ1 , µ2 > 0 为常数。

    注意

 正定性保证了系统的物理合理性：给定力矩必然产生确定的加速度，即 q̈ = M −1 (q)τnet
 总是有解。

    定理 1.2: 斜对称性质

    矩阵 Ṁ (q) − 2Vm (q, q̇) 为斜对称矩阵：

                            ζ T [Ṁ − 2Vm ]ζ = 0,     ∀ζ ∈ Rn

        这个性质反映了机械系统的能量守恒特性，是设计稳定控制器的关键。我们将在第二
章详细利用此性质。

    定理 1.3: 参数线性性（LIP）
    动力学方程可重写为参数线性形式：

                   M (q)q̈ + Vm (q, q̇)q̇ + F (q̇) + G(q) = Y (q, q̇, q̈)Θ

2.1 为什么需要自适应控制
        传统控制方法的假设：系统模型完全已知。但实际工程中面临诸多挑战：

            参数不确定性的来源

         • 测量误差：质量、长度、惯量等参数测量不准确

         • 时变特性：负载变化、磨损、温度影响

         • 建模简化：忽略的高阶动力学、未建模摩擦

         • 外部扰动：碰撞、风力、振动等


        自适应控制的核心思想：边控制，边学习（Control while Learning）。

2.2 滤波跟踪误差——巧妙的问题转化

 传统方法的困境

 若分别考虑位置误差 e 和速度误差 ė：

     • 需要设计两个控制目标：e → 0 和 ė → 0

     • 控制器设计复杂，稳定性分析困难

     • 两个目标可能相互冲突

 滤波跟踪误差的定义

                                          r = ė + Λe           (2)

 其中 Λ = diag(λ1 , λ2 , . . . , λn ) > 0

     这个定义的精妙之处：

 • 当 r → 0 时，误差系统变为 ė = −Λe（稳定的一阶系统）

 • 自动保证 (e, ė) → 0

 • 将两个目标统一为单一目标：r → 0


2.3 Lyapunov 稳定性理论

    直观理解
 Lyapunov 方法类比物理学的能量概念：

     1. 构造系统的” 能量函数”V （Lyapunov 函数）

     2. 如果能量持续减少（V̇ ≤ 0）

     3. 系统最终达到最低能量状态（平衡点）

 就像一个球在碗中滚动，最终会停在碗底！

5.1 仿真时序分析

        每个时间步的执行顺序

        1. t = k∆t：当前仿真时刻

        2. 轨迹生成：计算 qd(t), q̇d(t), q̈d(t)

        3. 误差计算：e = qd − q, ė = q̇d − q̇

        4. 控制计算：

            • 构建 r = ė + Λe
            • 计算 Y 矩阵

            • 输出 τ = Y Θ̂ + KD r

        5. 动力学响应：求解 q̈

        6. 状态更新：

            • q ← q + q̇∆t
            • q̇ ← q̇ + q̈∆t
              Θ̂     ˙
            • ← Θ̂ +Θ̂∆t
        7. t ← t + ∆t：进入下一时间步

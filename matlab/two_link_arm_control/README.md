# 二连杆机械臂控制：PID / 模型自适应(MBAC) / RBF 神经网络自适应

> 在同一台二连杆机械臂、同一条轨迹、同一初始条件下,实现并**定量对比**三种轨迹跟踪控制器:
> 经典 **PID** → 基于模型的自适应控制 **MBAC** → **RBF 神经网络**自适应控制。
> 三种控制器的自适应律均由 **Lyapunov 稳定性**设计,并用 RMSE、控制力矩范数、误差范数三个指标量化评估。
> MATLAB / Simulink 实现,`ode15s` 刚性求解。

---

## 1. 项目概述

机械臂轨迹跟踪的核心矛盾:动力学里的惯量、科氏/离心力、摩擦都随状态**非线性变化**,纯线性反馈(PID)精度有限。
本项目沿一条清晰的主线递进,并回答"知道多少模型信息 → 该用哪种控制器":

| 控制器 | 一句话本质 | 需要的先验知识 |
|---|---|---|
| **PID** | 只看跟踪误差反馈纠偏,不依赖任何模型 | 无 |
| **MBAC**（模型自适应） | 知道动力学结构、参数未知 → 在线估参数做前馈补偿 | 动力学结构（回归矩阵 Y） |
| **RBF-NN**（神经网络自适应） | 连结构都写不出 → 用神经网络在线逼近未知动力学 | 无（网络替代模型） |

> 主线:**从左到右,依赖的先验越来越少,在线学习的成分越来越多。** 这也是"经典控制 → 自适应控制 → 学习型控制"的演进缩影。

---

## 2. 被控对象

平面二连杆机械臂(2-DOF),动力学方程(对比实验所用模型,水平面、不含重力):

```
M(q)·q̈ + Vm(q,q̇)·q̇ + Fd·q̇ = τ
```

- `M(q)` 惯量矩阵(含 `cos q2` → 随构型变化)
- `Vm(q,q̇)` 科氏/离心力矩阵(两关节耦合,只在运动时出现)
- `Fd·q̇` 粘性摩擦
- 物理参数向量 `θ = [p1, p2, p3, Fd1, Fd2] = [3.473, 0.196, 0.242, 5.3, 1.1]`
- 期望轨迹 `qd = [0.5·sin t ; 2·cos(t/4)]`,初始带误差 `q(0)=qd(0)+[0.1; −0.2]` 以考察收敛

> 注:`RBF_Adaptive_Control.m` 为独立研究,采用另一套含**重力项 G(q) + 库伦摩擦**的模型与圆形轨迹,用于在更强非线性下检验 RBF 的逼近能力。

## 3. 三种控制器

### 3.1 PID（基线）

```
τ = Kp·e + Ki·∫e + Kd·ė ,   e = qd − q
Kp = diag(500,500),  Ki = diag(100,100),  Kd = diag(100,100)
```

不依赖模型,实现简单;代价是对重力/摩擦/耦合等"已知会捣乱的力"没有任何预判,只能等误差出现后被动纠正,跟踪精度有上限、力矩偏大且偏抖。作为对照组。

### 3.2 MBAC：基于模型的自适应控制

**核心洞察 —— 动力学线性于参数**:`M q̈ + Vm q̇ + Fd q̇` 可整理成 `Y(·)·θ`,其中 `Y` 全是可计算量、`θ` 是未知物理参数。

```
滤波误差   r  = ė + Λ·e          (Λ = diag(10,10))
控制律     τ  = −Y·θ̂ − K·r       (K = diag(30,30))   ← 前馈补偿 + 反馈兜底
自适应律   θ̂̇ = Γ·Yᵀ·r           (Γ 为 5×5 正定矩阵)
```

- 回归矩阵 `Y` 使用**参考速度/加速度** `q̇ᵣ=q̇d+Λe`、`q̈ᵣ=q̈d+Λė`(由期望轨迹算得、无噪声),而非实测 `q̈`。
- 参数从 `θ̂(0)=0` 起估,跟踪误差稳定收敛;前馈 `−Y·θ̂` 主动抵消惯量/科氏/摩擦,反馈 `−K·r` 只兜残差 → 比 PID 更准、力矩更省。
- 加 **参数投影**(下界 0.001)防止把惯量/摩擦估成负值导致发散。

### 3.3 RBF-NN：神经网络自适应

当动力学结构都写不出时,用 RBF 网络在线逼近整坨未知力:

```
控制律     u  = Ŵᵀ·H + K_D·r      (K_D = diag(50,50))
权重更新   Ŵ̇ = Γ·(H·rᵀ)          (Γ = 800)
```

- 150 个高斯基 `H_j = exp(−‖x−c_j‖² / 2b_j²)`,输入 `x=[q;q̇;qd;q̇d;q̈d]`(10 维),中心铺满工作空间。
- `ŴᵀH` 是网络逼近出的前馈力(正号、直接拟合),`K_D·r` 为鲁棒反馈兜底。
- 权重 `Ŵ(0)=0` 在线学习,**全程不需要任何动力学公式**。

> MBAC 与 RBF 的自适应律结构同构(`学习率 × 谁负责 × 还差多少`),区别在于 MBAC 估的是 **5 个有物理意义的参数**、RBF 估的是 **150×2 个无物理意义的网络权重**。

---

## 4. 稳定性：Lyapunov 设计（深度要点）

三种自适应律不是经验公式,而是由 **`V̇ ≤ 0`** 反推出来的。以 MBAC 为例,取能量函数

```
V = ½·rᵀ M(q) r + ½·θ̃ᵀ Γ⁻¹ θ̃       (θ̃ = θ̂ − θ)
```

对其求导后会出现一个符号不定的交叉项 `θ̃ᵀYᵀr`;**自适应律 `θ̂̇=Γ·Yᵀr` 正是为抵消该交叉项而设计的**,抵消后

```
V̇ = −rᵀ K r   （半负定）
```

由此直接得到**所有信号有界**,再经 **Barbalat 引理**得到跟踪误差 `r→0`。有两点需要强调:

- **跟踪收敛 ≠ 参数收敛到真值**:`θ̂→θ` 还需轨迹满足**持续激励(PE)**;PE 不足时,激励强的参数估得准、激励弱的会停在偏差上,但跟踪依旧良好。
- **MBAC 渐近收敛 vs RBF 一致最终有界(UUB)**:MBAC 动力学严格线性于参数,交叉项可消干净,误差趋于 0;RBF 是函数逼近、存在逼近误差,误差只收敛到一个小邻域。

## 5. 对比方法与指标

`ComparativeStudy_Main.m` 为保证公平,对三种控制器使用**完全相同**的动力学模型、期望轨迹与初始条件,各跑 30 s,用三把尺子量化:

| 指标 | 衡量 | 说明 |
|---|---|---|
| **RMSE**（均方根误差） | 准不准 | 跟踪误差的均方根,分关节与总体;越小越好 |
| **控制力矩范数 ‖τ‖** | 省不省劲 | 同等精度下力矩越小越优 |
| **误差范数 ‖e(t)‖**（对数刻度） | 收敛快慢/稳不稳 | 能看出自适应控制器前期的"学习过程" |

**结论(定性,实测数值见 `reports/04_三种控制算法对比研究.pdf`)**:在结构已知的本对象上,**MBAC 综合最优**(RMSE 最低、力矩最省,前馈接管重活);PID 作为基线能跟上但精度/力矩受限;RBF 在"结构已知"这一对 MBAC 有利的设定下接近 MBAC,其真正价值在于**结构未知时仍可用**。

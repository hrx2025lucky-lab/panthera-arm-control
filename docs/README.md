# Panthera 项目展示文档

**[返回项目首页：直接观看视频与实验图表](../README.md)**

本目录集中项目总结：方法、实现范围、实验条件、结果及图表。按同一台 Panthera 的完整控制与操作链组织。

| 阅读顺序 | 文档 | 主要回答 |
|---|---|---|
| 总览 | [项目总报告](project_summary.md) | 项目解决什么问题，各模块怎样连接，哪些结果有实验支撑？ |
| 01 | [机器人学与动力学](01_机器人学与动力学.md) | 六轴模型、FK/IK、雅可比和动力学怎样为任务服务？ |
| 02 | [运动控制与实验](02_运动控制与实验.md) | 怎样比较跟踪、柔顺、自适应、辨识和扰动响应？ |
| 03 | [运动规划与避障](03_运动规划与避障.md) | 如何从目标得到整机与携物可执行的连续轨迹？ |
| 04 | [接触操作与记录](04_接触操作与记录.md) | 如何判断抓住、放稳，并把真实仿真事务记录下来？ |
| 05 | [感知与视觉抓放](05_感知与视觉抓放.md) | 腕部 RGB-D 如何产生位姿、规划目标和完整任务？ |
| 06 | [学习模型与评价](06_学习模型与评价.md) | BC、ACT、DP、PPO 怎样适配，训练与任务怎样评价？ |
| 索引 | [成果目录](07_成果目录.md) | 除视频外有哪些图表、对照和系统成果？ |

图片与视频由 [`assets/`](../assets/)统一存放；[`evidence/results.json`](../evidence/results.json)给出数值摘要与指纹，[`evidence/control_curves.json`](../evidence/control_curves.json)保存选取的控制采样曲线。展示数据对应各自声明的 MuJoCo 或离线实验条件。

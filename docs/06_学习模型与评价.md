## Panthera 统一适配

学习模块共享六轴顺序、TCP、双指通道、模型指纹与任务数据。模型输出先转换为有界关节/夹爪参考，再由 CTC 与 MuJoCo 执行。数据按完整布局划分，区分当前实际状态、参考发生器状态、动作原点及未来标签。

![学习链路与评价](../assets/images/learning_chain.svg)

数据主要来自脚本专家和仿真纠正片段；20 Hz 区间可回溯到 500 Hz 源事务。训练、离线预测、实际参考跟踪、接触和完整任务分别评价，避免把某个误差下降直接说成抓放成功。

## 已实现模型与实验

| 方法 | Panthera 实现 | 训练或执行 |
|---|---|---|
| 状态 BC | 状态、参考与动作切片，归一化，MLP 等对照 | 比较参考信息和动作定义对离线预测的影响 |
| ACT | 45 维状态、CVAE/Transformer、8×7 动作块 | 1,345,191 参数，固定 3,600 次更新，检查点保存/重载与 MuJoCo 评价 |
| Diffusion Policy | 条件卷积去噪、DDIM、EMA，状态到动作块 | 317,831 参数，固定 3,600 次更新，动作块执行及长度对照 |
| 参考辅助 PPO | 88 维状态、7 维残差，脚本参考与奖励/终止接口 | 8,192 次策略采样、550 次实际优化器更新，正式 273,055 个新增物理步 |

ACT/DP 的原训练使用相同既有开发数据，网络、损失与输出聚合不同。其开发集首步关节 RMSE 分别约 0.296 / 0.576 mrad，动作块合并关节 RMSE 分别约 3.572 / 5.688 mrad。上述是动作目标预测误差，不是实际关节跟踪精度或独立测试集泛化结果。

## 物理任务评价

| 声明评价 | 完整任务 | 如何解释 |
|---|---|---|
| 状态 ACT | 0/2 | 已实际进入 MuJoCo；预测、目标与接触不能合并计为成功 |
| 状态 DP | 0/2 | 动作块执行长度对照 H=2/H=8 也分别为 0/2 |
| 参考辅助 PPO：训练策略 | 2/2 | 使用已知脚本参考辅助 |
| PPO：未训练策略 | 2/2 | 同任务与参考的必要对照 |
| PPO：零残差参考 | 2/2 | 说明原参考已经能完成这两例 |

PPO 三组均完成，因此这一结果不能独立归因出学习收益。ACT/DP 与 PPO 的参考信息不同，也不能直接据此排列算法能力。

## 数据恢复与执行诊断

对六个预抓取偏差条件记录恢复后抓放，得到四个非零偏差案例的 160 个合格恢复区间。接入 ACT 时核对 45 维观测的语义，保留实际关节位置作为动作原点。固定预算对照的首步关节误差降低 9.79%，八步误差增大 3.03%，完整任务仍为 0/2。

执行诊断按“策略目标 → 有界参考 → 实际 TCP → 双指接触 → 任务完成”追踪同一时刻的数据。一个控制器能把 TCP 跟到错误目标，并不意味着策略完成了正确抓取。

## 实践项目的结合范围

模型思想参考现有 ACT、Diffusion Policy 与 PPO 方法和抓取实践的任务组织。本项目集中完成 Panthera 的状态/动作接口、模型绑定、训练、环境、数据和独立评价。当前 ACT/DP 为状态策略；感知专题的 RGB-D 估计独立存在。

已实现的接口与训练流程可以作为项目技术内容；成功抓放展示视频采用传统规划与控制。记录、结果与范围见[实验摘要](../evidence/results.json)。

## Panthera 的统一模型

本项目把六个旋转关节、TCP、夹爪和物体分别建模。六轴关节向量 q 不混入第七个夹爪通道；双指的开度、接触和回读与六轴同拍执行。

| 约定 | 项目使用方式 |
|---|---|
| 单位 | 关节角 rad，长度 m，线速度 m/s，角速度 rad/s，力矩 N·m |
| TCP | `tool_link`，相对 `link6` 偏置 `[0.165, 0, 0] m`，在 link6 局部轴表达 |
| TOOL | 固定在工具上的坐标系，随末端姿态转动；X 沿工具前向 |
| BASE / WORLD | 本桌面场景基座系与世界系重合；接口仍区分各自表达 |
| 位姿记录 | 物体四元数采用 wxyz；局部坐标、世界坐标与欧拉角分别解释 |
| 物理时间 | 主要任务步长 0.002 s；500 Hz 指仿真离散频率 |

## 正运动学、逆运动学和雅可比

**FK** 输入六轴关节角，返回 TCP 位置 p 和旋转矩阵 R。它用于验证逆解、读取末端位置、重建相机外参和计算物体相对工具的位姿。

**IK** 输入目标 TCP 位姿，通过数值迭代寻找关节构型。项目支持伪逆和阻尼最小二乘，并以显式任务度量协调位置与姿态误差。位置单位 m、姿态误差 rad，不能直接把二者相加作为统一误差。

**雅可比 J** 表示当前构型附近的速度关系：

`[v_tcp; ω_tcp] = J(q) · q̇`

项目采用上三行线速度、下三行角速度的约定，空间速度在世界/基座方向表达。TOOL 遥操先用当前 `R_base_tool` 旋转线速度与角速度，再求关节速度参考。

TOOL 指令移动的是整个工具的 TCP；工具坐标系随末端一起运动。夹爪开合另由独立通道控制。常见 TOOL 绕长轴旋转对应工具 `ωx`，并非固定世界 Z 轴或第六关节局部轴。

## 动力学接口

动力学把“希望怎样运动”转换为所需力矩。项目使用质量矩阵 M(q)、速度相关项 h(q,q̇) 和重力 g(q) 构建控制输入；模型中的被动摩擦、外部作用与接触在各实验中单独处理。

`M(q) · q̈ + h(q, q̇) + g(q) = τ + τ_external + τ_passive`

上式给出概念上的力矩平衡。具体控制器是否补偿被动摩擦由该实验配置决定，不能把 CTC 一律理解成补偿了所有力。

- PD+g 使用误差反馈和重力项。
- CTC 根据参考加速度与误差计算虚拟加速度，再通过 M、速度项与 g 生成力矩。
- 笛卡尔阻抗在 TCP 规定弹簧/阻尼关系，通过 J 的转置映射为关节作用。
- 负载自适应复用六轴参考动力学，在线更新一个已声明结构的质量参数。

## 怎样验证这些接口

接口以解析约定、数值差分、独立 FK 重建、模型绑定检查以及实际 MuJoCo 回读交叉核对。视觉到规划实验对 122 个目标做原始 FK 重建；完整任务再检查碰撞、接触和最终物体状态。逆解数值误差小只说明目标匹配，任务仍需经过后续执行判定。

基础源码：[运动学](../panthera/core/kinematics.py)、[机器人模型与动力学](../panthera/core/robot.py)。MuJoCo 提供底层几何与动力学计算；项目工作是 Panthera 参数、TCP、求解接口和实验链路的适配与核验。

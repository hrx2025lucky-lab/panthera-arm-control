# Panthera-HT 项目总报告

[首页视频与图表](../README.md) · [全部展示文档](README.md) · [成果目录](07_成果目录.md)

## 项目目标与对象

面向机械臂控制与操作，将同一台 Panthera 六轴机械臂贯穿建模、运动控制、规划、抓放、视觉输入和学习实验。用动力学执行、接触状态与原始数据分别回答三个问题：参考是否跟得上，路径是否可执行，物体是否抓住并放稳。

机械臂六关节与双指夹爪采用独立状态；TCP 为 `tool_link`，相对 `link6` 偏置 `[0.165, 0, 0] m`。角度 rad、距离 m、力矩 N·m，核心任务物理步长 2 ms。实验基于 MuJoCo，硬件写入关闭。

## 系统组成

| 层次 | 输入 | 方法与输出 |
|---|---|---|
| 机器人学 | 关节状态、模型参数 | FK、IK、雅可比、质量矩阵与重力，为其余模块提供统一接口 |
| 规划 | TCP 目标、障碍、夹持关系 | IK、RRT-Connect、曲线与时间分配，输出 q/速度/加速度参考 |
| 控制 | 参考、实测状态 | PD+g、CTC、阻抗、自适应实验，输出六轴力矩 |
| 操作 | 实际机械臂、双指与物体状态 | 接触抓放监督、开度与力反馈、任务完成判断 |
| 感知 | 仿真 RGB-D、同拍机器人位姿 | 已知标记几何估计与坐标变换，输出抓取/放置提案 |
| 学习 | 状态数据、动作或控制参考 | BC、ACT、DP、参考辅助 PPO；输出有界动作并单独评价任务 |

## 代表性实验

| 实验 | 固定条件下的结果 | 解释 |
|---|---|---|
| PD+g / CTC | 关节 RMSE 7.191 / 4.731 mrad | 相同模型、正弦参考和力矩限制，声明各自增益 |
| 笛卡尔阻抗 | F/K 相对误差 1.584% | 固定姿态下 Z 向 −10 N，刚度 500 N/m |
| 单质量自适应 | 36 次、216,000 步；有载条件下降 96.22%–97.25% | 与冻结零负载估计比较；质心和单位质量惯量已知 |
| 辨识后闭环 | PD+g 改善，CTC 退化 | 同一冻结拟合参数分别用于重力或完整力矩修正 |
| 条件扰动区间 | 5 工况确认 106–114 ms，恢复 186–224 ms | 依赖摩擦边界；每工况晚期误报 0/1250 |
| S 曲线执行 | 六轴 RMSE 4.637 mrad | 固定路径、CTC，速度/加速度/jerk 约束 |
| 七粗高障碍抓放 | 两个预设规划种子均完成，53,919 步 | 固定布局，14–21 cm 障碍与 6 mm 查询裕量 |
| 100 布局抓放 | 100/100，1,793,308 步 | 名义模型、已知位姿、确定性 10×10 网格 |
| 视觉抓放 | 声明任务 1/2；故障拒绝 4/4 | 仿真腕部 RGB-D，已知标记、一次观察后执行 |

学习单独统计：ACT/DP 已完成训练与物理评价，声明任务各 0/2；参考辅助 PPO 的训练、未训练和零残差组均为 2/2。后者验证参考辅助链可执行，不能据此证明 PPO 带来任务收益。

## 实现工作与实践项目的结合

机械臂抓取与操作实践提供任务拆分、RRT、视觉目标和学习方法参考。本项目的结合包括：

1. **机器人适配**：以 Panthera 的六轴、TCP、双指、惯量和接触模型替代课程机器人，统一状态与动作顺序。
2. **控制主线**：建立跟踪、阻抗、自适应、模型误差、辨识与扰动对照；控制器的作用用同条件实验衡量。
3. **规划与执行**：将目标求解、整机/携物几何、连续参考和力矩执行连接起来，重新检查曲线和实际状态。
4. **接触与数据**：以承载、抬升、支撑、脱指和稳定条件判定任务，保存同拍事务供展示及学习接口使用。
5. **感知与学习**：视觉用同曝光位姿转换目标；学习绑定同一机器人与数据契约，区分预测、跟踪、接触与任务评价。

本项目采用 MuJoCo 的物理求解、官方来源的机器人几何和已有学习算法思想。物理引擎、RRT、ACT、DP、PPO 均不作为个人原创算法表述；项目工作体现在 Panthera 适配、实现集成、实验设计和结果分析。

## 结果与展示的对应

首页的三段动图分别展示粗高障碍抓放、连续轨迹抓放和视觉输入抓放。控制、自适应、辨识、扰动与接触求解由对照曲线和表格展示，不能由一个任务视频代替全部算法评价。

数值来自各自保存报告，原始报告标识和 SHA-256 在[结果摘要](../evidence/results.json)中列出。重复确定性运行用于检查再现性；不同轨迹、模型和任务的指标分别解释。展示摘要与选定采样曲线不等于完整原始数据包或真机验证。
